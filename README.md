# 🎬 Netflix Clone App

This is a fully responsive **Netflix clone frontend application** built with **React**, inspired by the original Netflix UI. It mimics the core layout and design of Netflix, including hero banners, horizontal movie sliders, and category-based rows. The goal of this project is to demonstrate front-end proficiency with real-world UI replication using reusable React components and responsive design.

---

## 🔗 Live Demo

🚀 https://netflix-clone-app-frontend.onrender.com/

---

## 📺 Features

- 🎞️ Home page with Netflix-style hero banner
- 📂 Multiple horizontal sliders for different movie categories
- 🖼️ Dynamic movie posters with hover animations
- ⚛️ Reusable components for row sections and thumbnails
- 🧩 Responsive design — works on all screen sizes
- 📦 Ready for integration with APIs like TMDB (if extended)
